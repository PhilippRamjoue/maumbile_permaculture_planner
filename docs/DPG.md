# Digital Public Good (DPG) readiness

How Maumbile maps to the [Digital Public Goods Standard](https://digitalpublicgoods.net/standard/)
(nine indicators), so a submission at <https://www.digitalpublicgoods.net/submission-guide> is a
matter of pasting links. Statuses are honest: **Met** means the evidence exists in this repository
today; **Open** means a small action remains (listed at the bottom). Review the current indicator
wording on the DPG site when you submit; it is updated periodically.

| # | Indicator | Status | Evidence |
|---|---|---|---|
| 1 | **Relevance to the Sustainable Development Goals** | Met | Helps smallholders and households design food-producing, water-wise land: **SDG 2** (Zero Hunger: sustainable, resilient food production), **SDG 13** (Climate Action: regenerative land use, water and shade planning) and **SDG 15** (Life on Land: soil, trees and habitat). Free, keyless, built first for Kenya and Tanzania. See the Vision in the [`README`](../README.md). |
| 2 | **Use of an approved open license** | Met | [GNU AGPL-3.0](../LICENSE), an OSI-approved license, covering all the code. Documentation is in the same repository under the same terms unless a file says otherwise. |
| 3 | **Clear ownership** | Open (one line) | The repository is owned and maintained by the GitHub user `PhilippRamjoue`; every image and release comes from this repository's CI. Add a copyright line with the owner's legal name to the README or a `NOTICE` file. |
| 4 | **Platform independence** | Met (see note) | Runs anywhere Docker runs; no proprietary service, cloud account or API key is required ([`DEPLOY.md`](DEPLOY.md), [`infra/`](../infra)). The database is PostgreSQL/PostGIS, the stack is FastAPI + React, and images are OCI images on a public registry. **Note for reviewers:** map imagery is data, not a dependency of the code. Esri World Imagery is the default (free for this non-commercial use, under its own terms), and the open-licensed **Sentinel-2 cloudless** provider is built in and selected by editing one seed file (the site-setup basemap by a build setting); elevation (Copernicus DEM) is openly licensed. See [`DATA_SOURCES.md`](DATA_SOURCES.md). |
| 5 | **Documentation** | Met | [`README`](../README.md) quickstart, [`ARCHITECTURE.md`](ARCHITECTURE.md), [`DEPLOY.md`](DEPLOY.md), [`OPERATIONS.md`](OPERATIONS.md), [`RELEASING.md`](RELEASING.md), [`CONTRIBUTING.md`](../CONTRIBUTING.md), API docs generated by FastAPI at `/docs`, and the [`CHANGELOG`](../CHANGELOG.md). A source repository, a launch/installation guide and developer docs are all public. |
| 6 | **Mechanism for extracting data** | Met | The platform holds user-created designs, not a shared dataset. Every plan exports as **GeoJSON** (round-trippable), PNG and PDF; see [`EXPORT.md`](EXPORT.md). No lock-in: the data model is plain geometry in WGS84. The database can be dumped with `infra/backup.sh`. |
| 7 | **Adherence to privacy and other applicable laws** | Met (instance-level) | [`PRIVACY.md`](PRIVACY.md) and [`TERMS.md`](TERMS.md): minimal data (email, password hash, the user's own sites), no analytics or tracking, third-party disclosures, export and erasure rights, GDPR basis. Operators of other instances remain responsible for their own jurisdiction. |
| 8 | **Adherence to standards and best practices** | Met | Open standards: GeoJSON (RFC 7946), WGS84/EPSG:4326, OpenAPI, OCI images, SPDX license. Engineering practice: typed code, linting, unit, integration (PostGIS) and browser tests in CI, dependency audit, additive migrations, [semantic versioning](RELEASING.md), 12-factor configuration with no secrets in the repository ([`DEPLOY.md`](DEPLOY.md)). |
| 9a | **Do no harm: data privacy and security** | Met | Argon2 password hashing, `httpOnly` + `Secure` cookies, login rate limiting, ownership checks, unguessable hashed share tokens, no tracking; see [`SECURITY.md`](../SECURITY.md) for reporting and [`PRIVACY.md`](PRIVACY.md). Site coordinates can be sensitive (they show where people live), so they are private to the owner unless a share link is created and can be revoked. |
| 9b | **Do no harm: inappropriate and illegal content** | Met (low risk) | The app has no public feed, comments or file hosting; the only user content is the owner's own geometry and labels, visible to others only through an unguessable link the owner creates. [`TERMS.md`](TERMS.md) §3–4 prohibit unlawful content and allow suspending accounts. |
| 9c | **Do no harm: protection from harassment** | Met (low risk) | No messaging, profiles or user-to-user interaction. [`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md) covers the project community. |

## Remaining actions before submitting

1. Add the copyright line with the owner's legal name (indicator 3).
2. Add a working contact address (data requests, security, conduct) in `PRIVACY.md`, `TERMS.md`,
   `SECURITY.md` and `CODE_OF_CONDUCT.md`, and enable GitHub *private vulnerability reporting*.
3. Make the repository and the first `v0.1.0` release public ([`RELEASING.md`](RELEASING.md)), with
   the GHCR packages set to public.
4. Optional, strengthens the case: a second deployment by an independent operator, and
   translations (Swahili first). Neither is required by the standard.
